# Felt Right — notes for Claude

- Edit files in `src/`, never `index.html` directly. After any change run `npm run build`, then `npm test` and `npm run check`.
- All `src/js/NN-*.js` files are concatenated into ONE classic `<script>` (shared globals, inline `onclick` handlers). Don't add `import`/`export` there; new files need a number prefix for load order.
- Pure rules (cards, hand eval, payouts, side pots, formats/variants) live in `supabase/functions/_shared/engine/*.js` as ES modules, shared with the server. `scripts/build.mjs` inlines them into the app wherever a `src/js` file has `/* @engine name.js */` (it strips `import`/`export`). Edit rules there, not in `src/js/01-engine.js`. Add a test in `tests/engine.test.mjs` for any rule change.
- Server migration plan: `docs/server-authoritative-migration.md` (one phase per PR, branch `server-rules-phase-N`).
- Backend: Supabase project `dcfsbtefwkcbdeqreiyx`. Tables: users, friendships, games, game_players, player_actions, private_hands, game_messages, payout_ledger, user_stats_public, user_stats_private. Every game is run by the `table` Edge Function (`supabase/functions/table`, rules in `_shared/engine/table.js`); phones render `games.state` and send moves. Any change under `supabase/functions/` needs a redeploy (Supabase connector). Demo mode is retired (no entry point; its old in-app engine in `src/js/16-deal.js`, `23-advance.js`, … is dead code awaiting removal).
- Home-game ledger entries are written only by the DB function `settle_home_game_ledger(game_id)` (both sides of each pair, from `games.state`). Don't insert home-game ledger rows from the client. Quitters keep their take-home stack in `cashedOutCents`.
- Chips are play chips only. Keep the ledger disclaimer wording intact (signup, Friends Ledger, cash-out).
- Hosted on GitHub Pages at `/Felt-Right/` from the repo root of `main`. `vendor/` (supabase-js, fonts) is generated by the build from `node_modules`; commit it with `index.html`.
- Android/iPhone apps: Capacitor (`android/`, `ios/`, `capacitor.config.json`, `src/js/41-native.js`). `npm run app:sync` rebuilds `www/` and copies it in. CI (`apps.yml`) builds the Android APK and an unsigned iOS simulator build. See `docs/native-apps.md`.
- Push notifications: events in `_shared/engine/notify.js` (tested in `tests/table.test.mjs`), senders in `_shared/push.js` (`tests/push.test.mjs`), device signup in `src/js/42-push.js` + `sw.js`. Deploying `table` must include `push.js` and `engine/notify.js`.
- Guests (`src/js/45-guest.js`, migration `20261117200000_guest_entry.sql`): anonymous Supabase users (`users.is_guest`). They join by invite link (`?join=` + `game_for_code`) and play; the database blocks guest hosting (unless the `guest_hosting` switch is on), friends and stats, and drops ledger rows involving a guest. The splash's "Play now" is behind the `guest_play` switch. Feature switches: `feature_flags` / `feature_status()` / `featureOn()`.
- No money anywhere: amounts are whole chips (`formatChips`, `chipAmt`, `chipNet`); Friends Ledger is called Standings.
